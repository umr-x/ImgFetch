## F7 - activeTab permission (kept)

- `activeTab` stays in manifest.json. An earlier attempt removed it, but
  `chrome.tabs.captureVisibleTab` requires either `<all_urls>` or
  `activeTab` in the manifest - broad host permissions (`https://*/*`,
  `http://*/*`) are not enough. Verified in a real browser: without
  `activeTab`, captureVisibleTab rejects with "Either the '<all_urls>' or
  'activeTab' permission is required", and screenshot capture fails with
  "ImgFetch could not capture this page."
- The Playwright e2e passes 10/10 without activeTab only because it does not
  exercise captureVisibleTab; real screenshot capture needs it.
- `docs/PERMISSIONS.md` and `PRIVACY.md` document activeTab honestly.
- `chrome.action.openPopup`: already wrapped in .catch; no sync throw path.
