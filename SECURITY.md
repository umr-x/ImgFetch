# ImgFetch - Security Policy

## Supported version

ImgFetch 1.0.0 (the current release). Older versions are not supported.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Use GitHub's
"Report a vulnerability" button on the repository
(https://github.com/umr-x/imgfetch), or open an issue marked Security.

Open an issue on the GitHub repository: https://github.com/umr-x/imgfetch/issues

Please include:

- What you did, step by step.
- What you expected vs. what happened.
- The ImgFetch version, browser and OS.
- A minimal proof of concept if you have one.

## Response

This is a best-effort project by an independent developer. Reports are
read and triaged, but there is no SLA. If the report is confirmed, a fix
is released and credited (unless you ask not to be).

## Technical details

The threat model and mitigations are documented in
[docs/security-model.md](docs/security-model.md).
